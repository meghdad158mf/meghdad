# طراحی — پایش پیام‌رسان ایتا (پروژه‌ی «جریان»)

`ita-monitoring-prototype.html` نسخه‌ی مستقل و قابل‌اجرا (باز کردن مستقیم در مرورگر) از طرحِ اولیه‌ی سایت است — بدون وابستگی به لینک آرتیفکت یا چت claude.ai.

## ساختار صفحات
نقشه‌ی سایت (پیش‌نمایش) → ورود (دوسطحی، فقط رمز عبور) → داشبورد → پست‌ها / آنالیز (+ تحلیل هوش‌مصنوعی) / کانال‌ها و افراد / خروجی‌گیری (فقط مدیر) / تنظیمات (فقط مدیر)

## وضعیت
تمام داده‌ها در این فایل نمونه (mock) و کلاینت‌ساید هستند. مرحله‌ی بعد، اتصال به داده‌ی واقعی (Postgres/PostgREST با pgcrypto + pgjwt برای احراز هویت دوسطحی مدیر/بیننده) است.
